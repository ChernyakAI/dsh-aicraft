# Работа с AICraft

Русский | [English](usage.en.md)

## Структура каталогов проекта

Настройки проекта и данные задач хранятся в файлах каталога `.aicraft/` рядом с исходным кодом. При использовании Git вся история работ сохраняется.

Структура каталога:

```text
.aicraft/                        # Настройки, знания и задачи проекта
├── project-rules.md             # Общие инструкции для агентов проекта
├── request.md                   # Шаблон постановки новой задачи
├── accounting.json              # Служебные данные учёта запусков для статистики
├── config/                      # Настройки процессов и ролей
│   ├── processes/               # Процессы, доступные при создании задачи
│   │   └── <process-id>.jsonc   # Название, этапы, роли и модели одного процесса
│   └── roles/                   # Роли, доступные в процессах проекта
│       └── <role-id>.md         # Редактируемая инструкция для конкретной роли
├── knowledge-base/              # Знания проекта: требования, решения, справочные материалы
└── tasks/                       # Все задачи проекта
    └── <task-id>/               # Данные и результаты одной задачи
        ├── request.md           # Постановка и условия приёмки этой задачи
        ├── state.json           # Статус задачи и состояния её этапов
        ├── process.json         # Копия процесса, выбранного при создании задачи
        ├── runs.json            # История запусков и ссылки на чаты исполнителей
        └── <step-id>/           # Рабочие материалы одного этапа
            ├── input-prompt.md  # Сохранённое задание для запуска исполнителя
            ├── report.md        # Итоговый отчёт исполнителя
            └── ...              # Другие документы и артефакты этапа
```

Идентификаторы в угловых скобках заменяются на имена ваших процессов, ролей, задач и этапов. Каталоги ролей и этапов заполняются по мере настройки; промпты, история запусков, отчёты и данные учёта появляются по мере работы. Служебные `.gitkeep` сохраняют пустые каталоги в Git и в схеме не показаны.

Изменение шаблона процесса не перестраивает начатую задачу: она использует собственный `process.json`. Сами чаты хранятся средствами DSH, а не в каталоге задачи.

Общие разделы нового входящего промпта используют язык demo-процесса. Для ручных и старых процессов без поля `language` используется английский. Язык ответов задаётся правилами проекта и ролью. Сохранённый промпт обновляется только через Reset to default и явное сохранение.

## Данные, Git и статистика

Настройки, постановки, состояния и артефакты задач находятся в каталоге `.aicraft/` вашего проекта. Их можно хранить в Git вместе с исходным кодом. Плагин не создаёт ветки, не выполняет коммиты и слияния. Если текущая ветка отличается от ветки, в которой создана задача, под списком задач появляется предупреждение с названиями обеих веток.

В текущем состоянии проекта допускается одна открытая задача. Для параллельных задач используйте отдельные ветки или рабочие каталоги. Если после слияния оказались доступны несколько открытых задач, команды изменения блокируются; вернитесь в ветку нужной задачи или согласуйте их состояния.

Панель обновляется по событиям. При необходимости перечитайте данные кнопкой **Refresh task**. Статистика обновляется после завершения исполнения. **Cost** показывает сумму доступных расчётов только для поддерживаемых моделей DeepSeek; локальные и другие модели в эту сумму не входят. Это оценка по тарифам, встроенным в плагин. Цены не обновляются онлайн. Подробности доступны по ссылкам **Details** и **Detailed usage**.
