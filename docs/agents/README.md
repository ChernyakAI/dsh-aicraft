# Information for agents

Perform only the work requested by the user:

- [Installing and updating inside DSH](install.md) — a release package, the current profile, the built-in `plugin_manager`, and activation checks.
- [Building from source](build.md) — code checks, building, and preparing an installable archive.

Building a package does not authorize installing or publishing it, changing user projects, or restarting DSH.
