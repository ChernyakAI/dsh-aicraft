# Установка, обновление и удаление AICraft

Русский | [English](install.en.md) · [AICraft](../README.md)

## Установка

AICraft можно установить через список плагинов **Discover** или из архива **GitHub Releases**. Оба способа предоставляют готовый плагин; самостоятельно собирать AICraft не требуется. Для зависимостей нужен доступ к npm registry, для Git-установки — также Git и доступ к GitHub.

### Через Discover
<a id="discover"></a>

1. Установите версию [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), совместимую с устанавливаемой версией плагина. В **Plugins** включите **Custom plugin indexes**.
2. Откройте **Plugins → Discover → Index sources** и добавьте адрес:

   `https://raw.githubusercontent.com/ChernyakAI/dsh-aicraft/master/dsh-plugin-index.json`

3. Нажмите **Refresh**, найдите **AICraft**, выберите совместимую версию в **Versions** и нажмите **Install**.
4. Проверьте результат менеджера и фактически установленную версию в **Plugins**. При ошибке остановитесь и устраните указанную причину; не обходите несовместимость разрешением на другую версию DSH.
5. Полностью завершите DSH и запустите заново. В Desktop используйте **Quit DeepSeek Harness**. Откройте **AICraft** в боковой панели.

Если источник недоступен или нужная версия отсутствует, установите опубликованный архив по инструкции ниже.

### Из архива GitHub Releases

> Менеджер плагинов доступен агенту в **Standard** и **Creator**, если доступен текущий профиль DSH.

1. Установите версию [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), совместимую с устанавливаемой версией плагина.
2. Скачайте установочный архив плагина (`.tgz`) из [Releases](https://github.com/ChernyakAI/dsh-aicraft/releases).
3. В DSH откройте **Plugins → Add plugin**, укажите путь к скачанному архиву и установите его. Распаковывать архив не нужно. Для установки зависимостей требуется доступ к npm registry.
4. Полностью завершите DSH и запустите заново. В Desktop используйте **Quit DeepSeek Harness**: закрытие окна может оставить приложение работающим в трее.
5. Откройте **AICraft** в боковой панели.

Если пользуетесь CLI, добавьте архив в тот профиль, с которым запускаете DSH:

```sh
dsh plugin --profile <profile> add "<path>/dsh-aicraft-<version>.tgz"
```

Для Desktop используется профиль `desktop`, для стандартного Web — `web`. Команда `dsh` должна относиться к вашей установке DSH.

## Обновление
<a id="updating"></a>

Для Git-установки откройте **Discover** и нажмите **Refresh**, чтобы получить новый список версий. Refresh обновляет только список. Для обновления самого AICraft дождитесь завершения исполнителей, выберите доступное обновление и подтвердите **Update**. Проверьте версию и результат загрузки, затем полностью перезапустите DSH. При ошибке следуйте сообщению менеджера; успешное восстановление прежней версии не гарантируется.

Для установки из архива сохранён прежний порядок: дождитесь завершения работы агента. Удалите прежний плагин через **Plugins**, затем установите новый `.tgz` и полностью перезапустите DSH. При удалении пакета файлы `.aicraft/` в пользовательских проектах сохраняются.

Если AICraft не появился или новая команда отвечает HTTP 404, проверьте версию DSH, выбранный профиль и полный выход из приложения перед повторным запуском.

## Удаление
<a id="uninstalling"></a>

1. Дождитесь завершения исполнителей AICraft.
2. В **Plugins** выберите установленный пакет **dsh-aicraft** и удалите его. Порядок одинаков для Git-установки и установки из архива.
3. Проверьте результат менеджера, затем полностью завершите DSH и запустите заново. В Desktop используйте **Quit DeepSeek Harness**.

При удалении плагина файлы `.aicraft/` в ваших проектах сохраняются. Индекс Discover — отдельный источник списка версий: удаление источника не удаляет установленный AICraft.
